The problems I hit building an SQL injection lab, and how I solved them

In four weeks I built a small virtual network with an attacker, a firewall, a web server and a database. I then broke into my own login page with SQL injection, fixed it, and made it reachable for teachers from anywhere. This page lets you explore every major problem on the way, from the big picture down to the exact commands and the real chat messages.
